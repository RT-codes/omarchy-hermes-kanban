# Tabler Icons attribution

The status icons in `../status/` are derived from the outline icons in
[Tabler Icons v3.46.0](https://github.com/tabler/tabler-icons/tree/v3.46.0),
licensed under the MIT License in this directory. Their strokes are normalized
to white so the Omarchy shell can apply theme-aware colors at runtime.

| --- | --- |
| Triage | `inbox` |
| Todo | `list-check` |
| Scheduled | `calendar-time` |
| Ready | `player-play` |
| Running | `loader-2` |
| Blocked | `alert-octagon` |
| Review | `eye-check` |
| Done | `circle-check` |
